# Reaper

REAPER is my main go-to DAW since 2016. 
Over the time, I have created a lot of presets, tracktemplates and more, that I would like to share.
I only share plugins that are valuable for others and that are 100% compatible stock effects.

[Back to Home](/README.md)

### How to install
Navigate to your REAPER folder and drag and drop the "fortress" folder into the correct template folder of REAPER.

Folder structure Example:
```
Before: REAPER/TrackTemplates (<-- your REAPER folder)
After:  REAPER/TrackTemplates/fortress

Before: REAPER/FXChains
After:  REAPER/FXChains/fortress

etc.
```
